1. 文件与目录操作 必考

命令说明
ls -la列出当前目录所有文件（含隐藏文件）+ 详细权限
cd /path切换目录
pwd打印当前所在目录的完整路径
mkdir -p a/b/c递归创建多级目录（-p 表示父目录不存在则自动创建）
cp -r src dst复制文件或目录（-r 递归复制整个文件夹）
mv old new移动 / 重命名文件
rm -rf path强制递归删除（危险操作，面试说知道但谨慎使用）
touch file.txt创建空文件 / 更新文件时间戳
cat file.txt查看文件全部内容（小文件）
less file.txt分页查看文件（大文件，q 退出，/ 搜索）
head -n 20 / tail -n 20查看文件头 / 尾 20 行
tail -f log.txt实时追踪日志文件新增内容（调试必备）
find . -name "*.py"在当前目录递归查找所有 .py 文件
ln -s target link创建软链接（类似 Windows 快捷方式）
面试常问：rm -rf / 是什么？→ 强制递归删除根目录下所有文件，系统直接崩溃。千万不要执行。

2. 文件权限 必考

权限表示法

# ls -la 输出示例
-rwxr-xr--  1 user group 4096 May 21 10:00 script.sh
└┬┘└┬┘└┬┘
 │  │  └── 其他人的权限 (r-- = 只读)
 │  └───── 所属组的权限 (r-x = 读+执行)
 └──────── 文件拥有者的权限 (rwx = 读+写+执行)
符号含义
r读 (read) = 4
w写 (write) = 2
x执行 (execute) = 1
-无权限 = 0

权限计算（数字相加）

# rwx = 4+2+1 = 7 （完全控制）
# rw- = 4+2+0 = 6 （读写）
# r-x = 4+0+1 = 5 （读+执行）
# r-- = 4+0+0 = 4 （只读）

# 最常用的组合：
chmod 755 script.sh   # 自己全权限，别人只能读+执行
chmod 644 file.txt    # 自己可读写，别人只读
chmod 600 secret.key  # 只有自己能读写（私钥文件）
chmod +x script.sh       # 给所有用户添加执行权限
命令说明
chmod 755 file修改文件权限
chown user:group file修改文件拥有者和所在组
sudo以超级管理员身份执行命令
面试记忆口诀：读4写2执行1，三个数字分别代表：拥有者、组、其他人。755 = 自己全权限，别人只能读和跑。

3. 文本处理三剑客 高频

grep — 文本搜索

grep "error" app.log           # 在文件中搜索包含 "error" 的行
grep -i "error" app.log          # 忽略大小写
grep -r "TODO" ./src             # 递归搜索目录下所有文件
grep -v "debug" app.log         # 排除包含 "debug" 的行（反向匹配）
grep -c "error" app.log         # 只统计匹配行数
ps aux | grep nginx                # 管道组合：从进程列表中过滤 nginx

sed — 流编辑器（批量替换）

sed 's/old/new/' file.txt        # 每行第一个 old 替换为 new（只输出不改文件）
sed 's/old/new/g' file.txt       # 全局替换（一行中所有 old 都替换）
sed -i 's/old/new/g' file.txt    # -i 直接修改文件内容（危险，先备份）
sed -n '5,10p' file.txt          # 只打印第5到第10行
sed '/^$/d' file.txt             # 删除空行

awk — 列处理

awk '{print $1, $3}' data.txt   # 打印第1列和第3列（默认空格分隔）
awk -F',' '{print $2}' data.csv   # -F 指定分隔符为逗号，打印第2列
awk '$3 > 100 {print $0}' file   # 第3列值大于100才打印整行
awk '{sum+=$1} END {print sum}' # 对第1列求和
面试场景："日志文件 10GB，找出包含 500 错误码的行" → grep "500" access.log
"提取 CSV 第3列并去重排序" → awk -F',' '{print $3}' data.csv | sort | uniq

4. 管道与重定向 必考

符号含义
cmd > file标准输出重定向到文件（覆盖）
cmd >> file标准输出追加到文件（不覆盖）
cmd 2> file标准错误重定向到文件
cmd 2>&1标准错误合并到标准输出（一起处理）
cmd < file从文件读取作为标准输入
cmd1 | cmd2管道：cmd1 的输出作为 cmd2 的输入
/dev/null"黑洞"设备，写入的数据被丢弃（静默输出）

实战组合：

# 把编译输出和错误都写入日志，终端不显示任何东西
npm install > build.log 2&1

# 静默运行（丢弃所有输出）
some_command > /dev/null 2&1

# 经典管道链：查找包含 "ERROR" 的日志行，取前10条
cat app.log | grep "ERROR" | head -n 10

# 统计某关键词出现次数
grep -o "ERROR" app.log | wc -l
标准输入/输出/错误编号：stdin=0, stdout=1, stderr=2。2>&1 就是把 stderr(2) 重定向到 stdout(1) 当前指向的位置。

5. 进程管理 高频

命令说明
ps aux列出所有进程的详细信息
ps aux | grep python查找 Python 相关进程
top / htop实时进程监控（CPU、内存排序）
kill PID优雅终止进程（发 SIGTERM 信号）
kill -9 PID强制杀死进程（SIGKILL，不给清理机会）
killall process_name按名称杀死所有同名进程
bg / fg后台 / 前台运行
jobs查看当前终端的后台任务
nohup cmd &后台运行且不受终端关闭影响
Ctrl+C / Ctrl+Z终止前台进程 / 暂停并放入后台

ps aux 输出解读：

USER  PID  %CPU %MEM    VSZ   RSS  TTY  STAT  START  TIME  COMMAND
root  1234  2.3  1.5  123456 45678 ?    S     10:00  0:05  nginx
#    │     │    │    │      │     │    │      │     │     │
#    │     │    │    │      │     │    │      │     │     └─ 进程名
#    │     │    │    │      │     │    │      │     └─ CPU累计时间
#    │     │    │    │      │     │    │      └─ 启动时间
#    │     │    │    │      │     │    └─ 状态(S=睡眠,R=运行,Z=僵尸)
#    │     │    │    │      │     └─ 终端(远程进程通常显示 ?)
#    │     │    │    │      └─ RSS: 实际物理内存(KB)
#    │     │    │    └─ VSZ: 虚拟内存(KB)
#    │     │    └─ 内存占用百分比
#    │     └─ CPU占用百分比
#    └─ 进程ID
面试区别点：kill（默认 -15/SIGTERM）让进程有机会清理资源后退出；kill -9（SIGKILL）直接暴力终止，进程无法做任何清理。优先用 kill，不行再用 kill -9。

6. 磁盘、内存、网络

命令说明
df -h查看磁盘分区使用情况（-h 人类可读：GB/MB）
du -sh path/查看目录占用空间大小
free -h查看内存使用情况
ping host测试网络连通性
curl url发起 HTTP 请求（测试 API 必备）
wget url下载文件
netstat -tlnp查看正在监听的端口
lsof -i :8000查看哪个进程占用 8000 端口
scp file user@host:/path远程拷贝文件（基于 SSH）
rsync -avz src/ dst/高效同步目录（增量传输）

实战场景：

# 服务器磁盘满了？快速找到大文件
du -sh /* 2>/dev/null | sort -rh | head -n 10

# 测试 API 是否正常
curl -s "https://api.example.com/health" | python -m json.tool

# 端口被占用？找到并杀死进程
lsof -i :8000
kill -9 12345

8. 面试高频概念题

8.1 软链接 vs 硬链接

软链接 (ln -s)类似快捷方式，存的是路径字符串。源文件删除后软链接失效。
硬链接 (ln)指向同一个 inode（文件数据块）。源文件"删除"后数据仍存在，直到所有硬链接都删除。

8.2 环境变量

# 临时设置（当前终端有效）
export MY_VAR="hello"

# 永久设置：写入 ~/.bashrc 或 ~/.zshrc
echo 'export MY_VAR="hello"' >> ~/.bashrc

# 查看所有环境变量
env
echo $PATH      # 查看 PATH（可执行文件搜索路径）

8.3 文件描述符（面试加分项）

Linux 一切皆文件。每个进程启动时默认打开三个文件描述符：

0 = stdin标准输入（键盘）
1 = stdout标准输出（屏幕）
2 = stderr标准错误（屏幕）

8.4 常见信号

信号含义
SIGTERM (15)请求进程终止（可被捕获，用于优雅关闭）
SIGKILL (9)强制杀死（不可被捕获或忽略）
SIGINT (2)中断信号（Ctrl+C 发送的信号）
SIGHUP (1)终端挂断（常用于让守护进程重载配置）
